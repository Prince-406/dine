# Dine Luxury Restaurant

A multi-page, component-driven web application built for a modern luxury dining venue. This application delivers an interactive reservation experience, dynamic menu showcases, and private event presentation across all device viewports.

---

## 🛠️ Tech Stack & Architecture

* **Framework:** Next.js (App Router)
* **Language:** TypeScript
* **Styling & UI:** Tailwind CSS, CSS Modules
* **Deployment:** Vercel

---

## Core Features

* **Interactive Reservation Form:** Built-in reservation manager allowing users to select dates, preferred dining times, and guest counts with client-side form validation.
* **Dynamic Menu & Specials Showcase:** Interactive tabbed interface displaying curated lunch, dinner, and seasonal dining options.
* **Private Events & Venue Highlights:** Modular section navigation highlighting family gatherings, special events, and social bookings with custom imagery layouts.
* **Fully Responsive Design:** Pixel-perfect layout built to adapt seamlessly across mobile, tablet, and desktop screens.

## ⚙️ Local Development Setup

To run this application locally on your machine, clone the repository and install the dependencies:

```bash
# 1. Clone the repository
git clone [https://github.com/YOUR_GITHUB_USERNAME/dine-restaurant.git](https://github.com/YOUR_GITHUB_USERNAME/dine-restaurant.git)

# 2. Navigate into the project directory
cd dine-restaurant

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
