# Dine Luxury Restaurant

A modern, multi-page web application designed for a high-end restaurant, featuring full reservation management and venue presentation.

---

## 🛠️ Tech Stack
* **Framework:** Next.js (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS, CSS Modules
* **Deployment:** Vercel

---

## ✨ Key Features
* **Component-Driven Architecture:** Modular layout components built for scalability and clean state handling.
* **Interactive Reservation Form:** Client-side validated form allowing users to select dates, times, and guest counts.
* **Menu & Event Showcases:** Dynamic tab views displaying curated menu items and private event highlights.
* **Pixel-Perfect UI:** Fully responsive design built from design specifications with accessibility in mind.

---
